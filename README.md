# Para minha princesa ✨

Uma surpresa romântica e interativa feita em HTML, CSS e JavaScript.

## O que o site tem

- abertura em formato de carta;
- animações suaves e estrelas;
- cartões com mensagens especiais;
- linha do tempo da história;
- mensagem final escondida;
- layout responsivo para celular e computador.

## Como visualizar

Abra o arquivo `index.html` no navegador ou publique o repositório com o GitHub Pages em **Settings → Pages → Deploy from a branch → main / root**.

## Como personalizar

Todo o conteúdo está no arquivo `index.html`. Procure os textos entre as tags `<p>`, `<h2>` e `<h3>` para trocar as mensagens.
